# PPTX Agent Notes

Follow the [note standard](../../notes/README.md). Search for the existing owner
before creating another record. Use the [template](../../notes/TEMPLATE.md) for
a new topic and choose the lifecycle that matches evidence.

Record the problem, actual decision or proposal, real alternatives, and costs.
Link API details to their owning documentation. Do not copy private documents,
credentials, session traffic, or machine-specific paths into a note.

Mark a proposal implemented only when the behavior or configuration is present
and verified to the stated extent. Preserve its original date when moving it;
record skipped live checks and unresolved compatibility explicitly. Repair links
before archiving. Run `pnpm check:repository` and relevant document checks.
