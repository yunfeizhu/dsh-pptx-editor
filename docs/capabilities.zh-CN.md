# 对话能力边界

[English](capabilities.md) · [简体中文](capabilities.zh-CN.md)

本文对应 `pptx-react-viewer`
3.19.2 和插件当前的接入实现。原生编辑器里有按钮，并不代表已发布供插件调用的接口。插件使用公开的
`addElement`、`updateElement`、`updateElements`、页面及撤销方法，不暴露组件内部 AI 桥接，也不修改读取快照来绕过编辑接口。

## 已接入对话

- 打开、读取、重新打开；新增、复制、删除、移动、隐藏页面；翻页和撤销重做。
- 新增文字、修改内容、字体、段落、列表和元素位置尺寸。
- 基础形状、元素复制删除、选区对齐和等间距分布。
- 新增表格、修改单元格和样式、调整无合并表格的行列结构及布局。
- 六类图表、新增及支持范围内的数据、标题和基础样式修改。
- 插入已接收的图片附件、裁剪、裁剪形状、不透明度、亮度和对比度。

单位、限制、示例和保存方式见[使用说明](usage.zh-CN.md)。每条命令独立执行，连续多步不构成一次原子撤销。

插件 0.2.0 新增
`edit_pptx_batch`：一次修改最多 100 个跨页现有元素，整体校验、整体应用，只占一步撤销。没有实际变化时返回
`unchanged`，不新增撤销步骤。它不包含新增／删除页面或表格、图表数据操作。

## 缺少已发布编辑接口

| 能力                       | 缺少的接口约定                             |
| -------------------------- | ------------------------------------------ |
| 动画和切换                 | 没有带撤销历史的公开页面动画、切换设置方法 |
| 主题、母版、版式和页面大小 | 没有公开的演示文稿、母版修改接口           |
| 演讲者备注和批注           | 存在读取模型，但没有带历史的公开编辑方法   |
| 组合、取消组合和图层顺序   | 没有保留引用关系的公开组合、排序操作       |
| 完整变更通知               | 没有完整的公开编辑订阅                     |

组件内部的一些辅助方法及 AI 编辑桥接能完成其中部分操作，但它们不属于已发布的外部接入约定。
`getSlides()`
返回的是快照，不能作为受支持的写入通道。本次没有为暴露这些能力新增依赖补丁；已有的自动保存兼容补丁与这些能力无关。

## 保存兼容性限制与尚未实现的接入

以下情况不能一概归为“组件没有公开 API”：

- 导入图表修改分类、类型、分组或方向，以及散点/气泡图新增与修改、网格线、底色和独立标题显隐控制，均因组件保存可能丢失修改而拒绝或未开放。组合图及特殊图表尚不支持。
- 表格字体名称、富文本单元格仅修改字体样式、包含富文本片段的表格增删行列，均因保存可能丢失修改或原有格式而未开放。
- 图片灰度能在编辑器显示，但保存重开后丢失，所以未开放对话修改参数。
- 合并表格可编辑起始单元格的值和样式；插件尚未实现合并、拆分，以及合并表格的结构修改。
- SmartArt、媒体/3D、公式、复杂图片效果和字符范围格式尚无经过验证的对话接入。部分能力有公开模型字段，但不能仅凭字段就保证渲染、引用关系、撤销和保存正确，需要单独完成兼容验证。

不支持对话操作的功能仍可使用原生界面，但界面存在不代表 PowerPoint 文件可无损往返。浏览器合成样本验证和真实 DSH 对话验证是两类证据，两者都不覆盖任意来源的所有文稿。
